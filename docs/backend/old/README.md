# Archived Backend Documentation

## Purpose & Archival Policy

1. **Preservation of Context**: Documents placed here preserve historical rationale and design discussions without confusing the active codebase state.
2. **Read-Only Reference**: Files in this directory are preserved for archival and reference purposes only. They do not represent the current state of the Flama backend.
3. **Active Ground Truth**: For current backend architecture, data models, and services, refer to:
