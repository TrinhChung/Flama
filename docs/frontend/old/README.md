# Archived Frontend Documentation

This directory (`docs/frontend/old/`) serves as the historical archive for retired frontend documentation, legacy component architecture drafts, and superseded migration plans.

---

## Purpose & Archival Policy

1. **Preservation of Context**: Documents placed here provide historical context on past architectural decisions without cluttering the active documentation hierarchy.
2. **Read-Only Reference**: Files in this directory are preserved for archival and reference purposes only. They do not represent the current state of the Flama React 19 SPA.
3. **Active Ground Truth**: For current frontend architecture, design systems, and guidelines, refer to:
   - [**`docs/frontend/ARCHITECTURE.md`**](../ARCHITECTURE.md)
   - [**`docs/frontend/README.md`**](../README.md)
   - [**`docs/frontend/tech-debt/README.md`**](../tech-debt/README.md)
